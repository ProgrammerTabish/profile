Projects

Three pieces of work I would happily walk you through, then everything public on my GitHub — pulled live, so this list is never out of date.

An MCP server for hardware diagnostics

Nokia Nuremberg · Python, HTTP streaming, MCP, Jira API

A streamable HTTP MCP server running on a lab gateway that connects language models in Cursor to both Jira and the diagnostics software. An engineer can ask a question in plain language and the server runs the matching test pipeline on the physical board, reads back results and correlates them with existing tickets.

Internal work — code stays with Nokia, but I can talk through the architecture.

Lab network monitoring & anomaly alerting

Nokia Nuremberg · Python, network diagnostics, SMTP alerting

The diagnostics lab had no way of knowing a link had degraded until a test run failed hours later. I specified the requirements from scratch and built continuous monitoring with anomaly detection and email notification, so the failure announces itself instead of being discovered.

Internal work — architecture and approach available on request.

City waste management with real-time GPS tracking

Bachelor thesis · IoT, GPS, OpenStreetMap, React Leaflet

An IoT application that tracks municipal waste collection vehicles in real time, giving the city administration a live map and citizens a way to see where a complaint stands. In evaluation it cut citizen complaint handling time by 17% and improved route efficiency by 25%.
